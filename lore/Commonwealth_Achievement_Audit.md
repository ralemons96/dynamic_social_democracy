# Commonwealth — Achievement Audit (game_over de-Germanization)

**Purpose:** the 127 `game_over` achievements still carry German titles + a few real-world references. This table is
for **you to annotate** before I execute. Style agreed: **faithful English translation of the German + reskin real
references to canon**; subtitle years → **Commonwealth calendar (+2365)** (1928→4293, 1932→4297, 1933→4298, 1934→4299).

**How to annotate:** edit the **`→ proposed title`** column (or scribble in **✎ notes**). The `id`, the icon image, and
the win-condition mechanics never change — only the displayed **title** and any flagged **subtitle residual**. Each
title is one unique string, so one swap updates all 3 on-screen copies.

**⚑ = a judgement call** (real person, pop-culture joke, pun, or a reskin choice) — your call matters most on these.
