# Commonwealth — Canonical Character First Names

Names are authored as plain text in the scenes (no first-name variable system). This is the
canonical first name for each named character, kept **globally unique** (the user's requirement:
no duplicate names). Western-European / Anglo style to match the surnames.

When adding prose that names a character, use the first name below. Most characters are shown by
**surname only** in normal play — only add a first name where a full name reads naturally.
