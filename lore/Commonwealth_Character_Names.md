# Commonwealth — Canonical Character Names

Names are authored as plain text in the scenes (no first-name variable system). This is the
canonical name for each character. **Source of truth = the lore compact**
([Commonwealth_Lore_Compact.md](Commonwealth_Lore_Compact.md)); where it specifies a name that
wins, otherwise a unique Western/Anglo coinage in the lore's style. Kept globally unique.

Most characters are shown by **surname only** in play — add a first name only where a full name
reads naturally. **(she/her)** marks characters whose prose pronouns must read female.
